# Youssif Elhadad: Portfolio

Personal portfolio website of **Youssif Elhadad**, a Computer and Information Science student at Mansoura University (class of 2028) and aspiring Data Engineer.

## What's on the site

- **About and strengths**, with a `profile.json` code window.
- **Technical skills**: rated skills, tools I'm learning, and topics I've studied.
- **How I can help**: database design, ERDs, data cleaning with Python, and small ETL scripts.
- **Training**: Digital Egypt Pioneers Initiative (DEPI), Data Engineering track, and ACPC problem solving.
- **Projects**: University Database and ERD, Hospital Database and ERD, Car Company Database and ERD, Linear System Solver, and Electricity Consumption Prediction (in progress). Database projects have in-page SQL and ERD viewers.
- **Contact** and a CV download.

## Design

Dark violet theme with a faint grid, code windows, and a layout that adapts to phones, tablets, and desktops. Four small code blocks float beside the page on wide screens. The site respects the "reduce motion" setting.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole site: HTML, CSS, and JavaScript in one file |
| `assets/profile.jpg` | Portrait used in the hero section |
| `assets/Youssif-Elhadad-CV.pdf` | CV behind the "Download CV" buttons |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

## Publish with GitHub Pages

1. Create a repository (for a personal site, name it `JoeElhadad0.github.io`) and upload all these files to the main branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://JoeElhadad0.github.io`.

## Edit it

Colors live in the `:root` block at the top of the `<style>` section in `index.html`. Text, projects, and links are plain HTML further down.

## Built with

HTML, CSS, and a little vanilla JavaScript. Fonts (Space Grotesk, Inter, JetBrains Mono) load from Google Fonts. No frameworks or build step.
